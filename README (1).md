# Dashboard de Vendas no Excel

## Sobre o projeto
Este projeto apresenta um dashboard de vendas desenvolvido no Microsoft Excel para transformar dados tabulares em indicadores visuais que apoiam a análise de desempenho e a tomada de decisões.

## O que está incluído
- **Dashboard:** indicadores de faturamento, unidades vendidas e quantidade de pedidos.
- **Gráficos:** faturamento por produto, faturamento por canal e evolução mensal.
- **Base de Vendas:** tabela estruturada para organizar os dados e servir de fonte para os indicadores.
- **Fórmulas:** cálculos automáticos de faturamento e consolidação dos resultados.

## Arquivos
- `dashboard_vendas_template.xlsx` — planilha Excel com o dashboard e uma base demonstrativa.
- `README.md` — documentação do projeto.

## Dados utilizados
A planilha fornecida nesta versão contém **dados demonstrativos fictícios**, criados apenas para exemplificar a estrutura e o funcionamento do dashboard. Eles não representam vendas reais nem substituem a base oficial disponibilizada no desafio da DIO.

Para reproduzir o desafio com os dados oficiais:
1. Baixe a base de dados indicada na página do desafio.
2. Abra a aba **Base de Vendas** e substitua os registros demonstrativos, mantendo os cabeçalhos e a estrutura das colunas.
3. Confira se as fórmulas e os gráficos refletem corretamente a nova base.
4. Salve o arquivo e revise os indicadores antes de publicar no GitHub.

## Como usar
1. Baixe e abra `dashboard_vendas_template.xlsx` no Microsoft Excel.
2. Consulte a aba **Dashboard** para visualizar os indicadores e gráficos.
3. Utilize a aba **Base de Vendas** para inserir ou substituir os registros.
4. Caso a quantidade de linhas seja alterada, ajuste os intervalos das fórmulas e dos gráficos, se necessário.

## Ferramentas
- Microsoft Excel
- Tabelas, fórmulas e gráficos do Excel

## Observação
Este arquivo é uma versão inicial demonstrativa. Para entregar o desafio com fidelidade à base e ao dashboard de referência da DIO, é necessário substituir os dados fictícios pela base oficial e validar os campos e indicadores.
